# Dear Box

[![Dear Box — тайский чай и кофе, Уральск](https://dearbox.kz/og.png?v=2)](https://dearbox.kz)

Сайт-меню для кофейни тайского чая в Уральске — **[dearbox.kz](https://dearbox.kz)**.

На сайте можно собрать корзину и оформить заказ. А у бариста есть своя
админка: отметил, что напиток закончился, — и он сразу гаснет в меню.

## Что есть

- Меню на русском и казахском, светлая и тёмная тема
- Корзина и заказ — с доставкой или самовывозом
- Админка наличия для бариста — `/admin`, с телефона

## Как устроено

Обычные HTML, CSS и JavaScript, без фреймворков. PHP — только для админки.

```
DearBoxV1/        сайт (исходники с комментариями)
├── index.html    страница, всё меню — внутри неё
├── app.js
├── styles.css
├── stock.php     наличие для сайта
└── admin/        админка
tools/            сборка
```

Гостю уходит сжатая копия без комментариев — её собирает `npm run build`.
На сервер сайт выкладывается сам, после каждого коммита.

Админка закрыта паролем (хранится только хэш), ограничивает попытки входа
и проверяет каждое изменение. Паролей и других секретов в репозитории нет.

## Запустить у себя

```bash
npm install
npm run build
php -S 127.0.0.1:8779 -t public
```

Для админки рядом с папкой `public` нужен файл `dearbox-data/setup.txt` —
тогда `/admin` предложит задать пароль.
